### This repository has been archived.
This means that the download links in Github Actions will expire and become unavailable. You can get a new file by:

1. Forking this repository
2. In the fork, going to "Actions"
3. Clicking on "build" off to the left
4. Clicking on "Run Workflow" to the right
5. Select the version to build for in the dropdown - you're looking to take your version and then finding the **closest OLDER version**.
6. Clicking on the (now blue) "Run Workflow" button
7. Wait for the workflow to complete
8. Scroll all the way down on the page, and download the artifact
9. Profit!
